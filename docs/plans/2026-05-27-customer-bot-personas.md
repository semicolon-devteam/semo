# SEMO Customer 봇 페르소나 카탈로그 (초안)

> 발의: reus 요청 / 작성: 2026-05-27
> 맥락: SEMO Dashboard v5 트랙 B §6. [통합 결정문](./2026-05-27-semo-dashboard-v5-track-b-predesign.md) 참조.
> 후속: PlanClaw 가 일러스트 컨셉·1인칭 자기소개·리뷰 mock 보완 → DesignClaw 가 캐릭터 디자인.

---

## 0. 원칙

- **7봇 (semiclaw·planclaw·designclaw·workclaw·reviewclaw·infraclaw·growthclaw) 은 Customer 카탈로그에 등장하지 않는다.** 그들은 세미콜론 팀 내부 운영용 + 인큐베이팅 프로젝트용. preset 으로 라이브러리에는 등록되지만 `metadata.audience='internal'` 로 Customer 노출에서 제외.
- Customer 봇 이름은 **친근한 한국어 닉네임**. "에이전트", "오케스트레이션" 같은 용어 X.
- 1인칭 자기소개. 캐릭터는 일러스트레이션 — 추상 도형 X, 사진풍 X.
- 각 카드 정보: 닉네임 + 직책 + 한 줄 소개 + 핵심 일 3-5개 + 필요 통합 + 가격 모델 + 추천 업종.

---

## 1. 1차 출시 권장 라인업 (5개)

소상공인이 가장 즉시 효과를 체감할 수 있는 5개. MVP 베타에 우선 포함.

### 1.1 주문이 · 주문 응대 직원

- **한 줄**: "카카오톡으로 들어오는 주문·문의를 24시간 받아드려요."
- **핵심 일**:
  1. 카카오톡 채널 메시지 자동 응대 (단순 FAQ → 즉답, 복잡 → 사장님에게 전달)
  2. 단골 손님 이름·취향 기억 → 다음 방문 시 호칭 + 추천
  3. 주문 시간·메뉴 통계 → 매일 아침 요약
  4. 예약·문의 일정을 사장님 캘린더에 등록
  5. 사장님 응답이 필요한 케이스는 알림 (모바일 푸시)
- **필요 통합**: 카카오톡 채널, Google/네이버 캘린더
- **가격 모델**: included (Starter 플랜부터)
- **추천 업종**: 카페·미용실·소매점·1인 컨설턴트

### 1.2 새미 · 회계·세무 도우미

- **한 줄**: "영수증·매출·세금을 정리해드려요. 사장님은 사진만 찍어서 보내주세요."
- **핵심 일**:
  1. 영수증 사진 → OCR → 비용 카테고리 자동 분류
  2. 일·주·월 매출 리포트 자동 생성
  3. 부가세 신고 시즌 알림 + 자료 준비 도움
  4. 단골 거래처 별 결제 내역 정리
  5. 세금계산서 발행 (사업자 등록증 등록 시)
- **필요 통합**: 카드사 알림, 은행 OpenAPI, 팝빌 (세금계산서)
- **가격 모델**: addon (월 +₩15,000)
- **추천 업종**: 모든 사업자

### 1.3 재고지기 · 재고 관리 직원

- **한 줄**: "재고가 떨어지기 전에 알려드리고, 발주서까지 만들어드려요."
- **핵심 일**:
  1. 주요 재료·상품 재고 트래킹 (수동 입력 + POS 연동)
  2. 소진 예측 → "이번 주말 우유 떨어집니다" 사전 알림
  3. 단골 공급처별 발주서 자동 생성 (사장님 confirm 후 전송)
  4. 재고 회전율 분석 → 잘 안 나가는 재료 알림
  5. 유통기한 임박 알림
- **필요 통합**: POS (배달의민족 사장님·요기요 사장님·테이블링 등), 스마트스토어
- **가격 모델**: addon (월 +₩10,000)
- **추천 업종**: 카페·식당·소매점·온라인쇼핑몰

### 1.4 마케타 · SNS 마케팅 도우미

- **한 줄**: "인스타·블로그·네이버 플레이스 글을 같이 써드려요."
- **핵심 일**:
  1. 신메뉴·이벤트 정보 → 인스타 캡션 + 해시태그 작성
  2. 사진 한 장 → 자동으로 보정 + 톤 일관성 유지
  3. 네이버 플레이스 리뷰 답글 초안 작성 (긍정·부정·중립 분기)
  4. 주간 SNS 통계 + 다음 주 콘텐츠 캘린더 제안
  5. 경쟁 가게 동향 모니터 (선택)
- **필요 통합**: 인스타그램 비즈니스, 네이버 플레이스, 블로그
- **가격 모델**: plan_required (Pro 플랜부터)
- **추천 업종**: 카페·미용실·식당·소매점

### 1.5 스케줄러 · 일정·예약 비서

- **한 줄**: "예약 받고, 알림 보내고, 노쇼 줄여드려요."
- **핵심 일**:
  1. 카카오톡·전화·메시지로 들어오는 예약을 캘린더에 자동 등록
  2. 예약 1일 전 / 2시간 전 리마인드 (카톡 자동 발송)
  3. 노쇼 패턴 분석 → 노쇼 위험 손님 사전 경고
  4. 사장님 휴무·휴게 시간 자동 안내
  5. 빈 시간대 프로모션 제안 (선택)
- **필요 통합**: 네이버 예약, 캐치테이블, 카카오톡, Google 캘린더
- **가격 모델**: included (Starter 플랜부터)
- **추천 업종**: 미용실·1:1 컨설턴트·병원·스튜디오

## 2. 2차 라인업 (Phase 1.5)

1차 출시 후 사용자 피드백 보고 추가. 7개.

### 2.1 정산이 · 매출 리포트 작가

- 일·주·월 매출/이익 자동 분석 + 트렌드 리포트 (PDF/모바일).
- 통합: POS·은행·카드사. 가격: addon (월 +₩5,000).

### 2.2 친절이 · VOC·리뷰 응답

- 네이버/배달앱 리뷰에 톤 살린 답글 + 부정 리뷰 사장님 알림.
- 통합: 네이버 플레이스·배달의민족·요기요. 가격: included.

### 2.3 메뉴쟁이 · 상품 등록·관리

- 신메뉴 사진 → 스마트스토어·배달앱 동시 등록 + 가격 변경 동기화.
- 통합: 스마트스토어·배달앱. 가격: addon (월 +₩10,000).

### 2.4 알림이 · 고객 CRM

- 단골 생일·기념일 알림 + 자동 쿠폰 발송.
- 통합: 카카오 알림톡. 가격: addon (월 +₩8,000).

### 2.5 모집책 · 채용·관리

- 알바몬·인디드 공고 자동 게시 + 지원자 1차 응대 + 면접 일정 조율.
- 통합: 알바몬·잡코리아·이메일. 가격: addon (월 +₩20,000).

### 2.6 안내봇 · 매장 FAQ

- 매장 위치·메뉴·가격·휴무 등 자주 묻는 질문 24h 자동 응대.
- 통합: 카카오톡·웹챗 위젯. 가격: included (Free 플랜에도 1개).

### 2.7 응대왕 · 다국어 고객응대 (관광지·외국인 손님 많은 곳)

- 영어·중국어·일본어로 카톡·매장 QR 응대.
- 통합: 카카오톡 채널·번역 API. 가격: plan_required (Pro 플랜부터).

## 3. 디자인 가이드 (DesignClaw 인계)

- 각 봇은 **한 가지 직업 캐릭터**: 주문이 = 헤드셋 낀 카운터 직원, 새미 = 안경 쓴 회계원, 재고지기 = 클립보드 든 창고 직원 등.
- 인종·성별·연령 다양성 — 12개 캐릭터에서 한쪽으로 쏠리지 않게.
- 표정: 친근하지만 프로페셔널. 너무 만화적 X, 너무 사실적 X.
- 컬러: 각 봇마다 액센트 컬러 1개 (총 12색이 디자인 시스템 §3.2 의 아바타 팔레트와 일치).
- 사이즈: 카드용 256×256, 헤더용 64×64, 채팅 아이콘용 32×32. 모두 같은 비율 페이스 크롭.

## 5. 7봇과의 매핑 (참고)

내부적으로 7봇이 Customer 봇 backend 를 일부 담당할 수 있음. 사용자에게 노출되진 않음.

| Customer 봇 | 백엔드 7봇                   | 메모                                                 |
| ----------- | ---------------------------- | ---------------------------------------------------- |
| 주문이      | (신규) — 7봇과 별개 채팅 봇  | 라이트한 LLM (Haiku 4.5)                             |
| 새미        | growthclaw + (신규) OCR 워커 | 회계 도메인 강화 필요                                |
| 재고지기    | (신규) — 7봇과 별개          | POS 연동 별도                                        |
| 마케타      | growthclaw                   | 콘텐츠 생성 강함                                     |
| 스케줄러    | (신규) — 7봇과 별개          | 캘린더 통합                                          |
| 정산이      | growthclaw                   | 리포트 생성                                          |
| 친절이      | growthclaw                   | 톤 살린 답글                                         |
| 메뉴쟁이    | (신규)                       | 상품 등록 자동화                                     |
| 알림이      | (신규)                       | CRM 워크플로우                                       |
| 모집책      | planclaw + workclaw          | 채용 공고는 planclaw, 지원자 응대는 workclaw 톤 활용 |
| 안내봇      | (신규) — 가볍게              | FAQ 매칭만                                           |
| 응대왕      | (신규)                       | 번역 API 의존                                        |

→ 결론: 12개 중 4개 (마케타·정산이·친절이·모집책 일부) 만 7봇 재활용 가능. 나머지 8개는 신규 봇 정의 + 워커 필요. PlanClaw 가 정의 작성, WorkClaw 가 구현.
