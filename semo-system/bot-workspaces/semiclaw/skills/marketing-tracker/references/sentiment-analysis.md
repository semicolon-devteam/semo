# 댓글 감정 분석 가이드

## 권장 방식: LLM 기반 분석

댓글 텍스트를 수집한 후, LLM에 다음 프롬프트로 분석 요청:

```
다음 댓글들의 여론을 분석해줘. 각 댓글을 긍정/중립/부정으로 분류하고, 전체 분위기를 요약해.
특히 "광고", "스팸" 의심 여부와, 실제 관심/호응 여부를 구분해줘.

댓글 목록:
{comment_texts}
```

## 대안: 키워드 기반 (간이)

LLM 호출이 어려울 때 사용. 정확도 낮음.

### 긍정 키워드
좋아, 좋네, 좋다, 감사, 고마워, 최고, 훌륭, 추천, 굿, 대박, 갓, 미쳤다, 존맛, 
인정, 찐이다, 실화냐, 개좋, 혜자, 가성비, 존버, 레전드, 킹왕짱, ㄹㅇ, 쩐다,
ㅊㅊ, 강추, 존잘, 이쁘다, 예쁘다, 멋지다, 편하다, 유용하다, 도움, 알려줘서

### 부정 키워드  
별로, 최악, 나쁘다, 비추, 실망, 광고, 스팸, 홍보, 돈받고, 협찬, 뒷광고,
구라, 사기, 쓰레기, 거르자, 노답, 어그로, 낚시, 허위, 과대, 조작,
ㅂㅊ, 거름, 폰팔이, 체험단, 기자단, 바이럴, 블로거, 인플루언서

### 경고 키워드 (삭제 위험 신호)
신고, 광고글, 홍보글, 삭제해라, 나가라, 차단, 영정, 강퇴

## 분석 결과 형식

```json
{
  "total": 15,
  "positive": 8,
  "neutral": 4, 
  "negative": 3,
  "risk_signals": ["광고 의심 댓글 2건"],
  "summary": "전반적으로 호응이 좋으나 광고 의심 댓글 있음. 주의 필요."
}
```
