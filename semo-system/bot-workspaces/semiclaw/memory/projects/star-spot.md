# Star Spot / CelebPin 프로젝트

## 개요
- 채널: #proj-star-spot
- 조사: Roki + GrowthClaw(Kai) 진행 (2026-03-09)

## 서비스 컨셉
- **이름 1순위**: CelebPin (celebpin.com/io/app 도메인 확보 가능)
- **핵심 기능**: 지도 기반 셀럽 검색 + 실시간 팬 커뮤니티
- **타겟**: 연예인/유튜버/스트리머/인플루언서 팬들
- **차별화**: 크로스 팬덤 통합 + 지도 UI (기존 플랫폼에 없음)

## 법적 안전장치 (필수)
- 이용약관 (중개자 면책 명시)
- Notice & Takedown 프로세스 (신고 시 24~72시간 내 삭제)
- 커뮤니티 가이드라인 (초상권/저작권 침해 금지)
- 개인정보 처리방침 (GDPR 준수)
- AI 필터링 (비속어, 음란물 차단)

## MVP 타겟: 스트리머/버튜버 (1순위)
**이유:**
- 공식 플랫폼 부재 (위버스 같은 대형 서비스 없음)
- 명확한 Pain Point (방송 일정 관리, 합방 정보 파편화)
- 버컴퍼니(v-company.xyz) 같은 소규모 팬사이트만 존재

**핵심 기능:**
1. 방송 일정표
2. LIVE 알림
3. 합방 표시
4. 커뮤니티 게시판
5. 팬아트 갤러리

## 번역 기능 비용분석 보고서 (Roki 조사, 3/9)
**목적**: 글로벌 확장을 위한 실시간 번역 아키텍처 + 수익화 전략

### NMT(기존 번역 API) 비용
| 서비스 | 백만자당 비용 | 비고 |
|---|---|---|
| 파파고 | ₩20,000 | 동아시아 언어 강점, 무료 티어 없음 |
| Google Cloud | $20 | 월 50만자 무료, 광범위 언어 |
| DeepL | $25 + 월$5.49 기본료 | 유럽권 정확도 최고, 무료시 데이터 학습 이슈 |

### LLM 기반 번역 비용 (혁신적 저비용)
| 모델 | Input/1M토큰 | Output/1M토큰 |
|---|---|---|
| Gemini 1.5 Flash-8B | $0.04 | $0.15 |
| Gemini 2.0 Flash | $0.10 | $0.40 |
| GPT-4o mini | $0.15 | $0.60 |
- DeepL 대비 최대 800배 비용 절감 가능
- 한국어 토큰 세금: 영어 대비 1.6~2.36배 토큰 소요 (그래도 NMT보다 저렴)

### 권장 아키텍처
1. **저비용 LLM** (Gemini 1.5 Flash) + **Redis 캐싱** + **온디바이스 번역** 조합
2. iOS: Apple 번역 프레임워크 (서버비용 0), Android: Google ML Kit
3. 서버는 검색 인덱싱/커뮤니티용, 개인 피드는 온디바이스 우선
4. Cache-aside 패턴으로 중복 번역 방지

### 3단계 수익화 전략
1. **0~6개월** (시장 침투): LLM으로 번역 전면 무료, 데이터 수집
2. **7~18개월** (하이브리드): 일 30회 무료 → 초과시 보상형 광고, StarSpot Pass $1.99~$2.99/월
3. **19개월~** (슈퍼팬): 월 $4.99 멤버십 (실시간 음성 통번역, 슬랭 해설), B2B 데이터 대시보드

### 예상 운영 지표 (MAU 50만 기준)
- 월간 번역 토큰: 75억 토큰
- API 비용 (Gemini Flash): ~$750/월 (~₩100만)
- 멤버십 수익 (2% 전환): $25,000/월 (~₩3,300만)
- 번역 비용 = 매출의 5% 미만

### 리스크 관리
- 글로사리 API로 팬덤 신조어/슬랭 사전 구축
- 공식 공지: MTPE (AI 초안 → 인간 검수), 비용 40~60% 절감 + 정확도 97%
- 개인정보 마스킹: 번역 요청 시 식별정보 제외, GDPR/CCPA 준수
- DeepL 무료버전 데이터 학습 이슈 → 유료 플랜 필수

### 경쟁사 번역 수익화 벤치마크
- 위버스: 무료(기본 번역) → $2.50/월(실시간 라이브 번역) → $4.00(프리미엄)
- 버블: 월 ₩4,500, 번역 기본 포함
- Discord iTranslator: 무료(1만자) → €9.99/월(무제한) → €24.99(GPT 기반)
