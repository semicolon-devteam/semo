# star-spot 프로젝트 (GitHub 확인 완료 — 2026-03-15)

## 프로젝트 개요 (Epic #4 기준)
**범용 셀럽 팬 커뮤니티 플랫폼** — 엔터사/셀럽 유형 제한 없는 글로벌 서비스

### 핵심 문제 인식
1. **플랫폼 파편화**: 위버스(하이브), 버블(SM/JYP), 버컴퍼니(스트리머) 등 소속사별 분산
2. **친밀감 vs 기능성 트레이드오프**: 버블=친밀하지만 기능 단순, 위버스=기능 많지만 친밀감 약함
3. **실시간 소통 부재**: Threads 스타일 실시간 대화 공간 부족

### 솔루션
- **범용 플랫폼**: 모든 셀럽 (연예인, 스트리머, 유튜버) 커버
- **MVP 킬러 피처**: Threads (실시간 대화)
- **Phase 2+ 차별화**: 셀럽 카테고리별 맞춤 기능

## MVP 스코프 (Phase 1 — 3월 런칭 목표)

### 코어 기능 (이미 구현 진행 중)
1. **셀럽 선택** (#7, #32)
   - 검색/필터 (배우, 아이돌, 스트리머, 인플루언서)
   - 3열 그리드 셀럽 리스트
   - 정렬: 인기순 (맛집 수) | 가나다순 | 최신 등록순

2. **Threads** (#8, #13, #45, #46)
   - 실시간 타임라인 (WebSocket)
   - 글 작성 (텍스트, 이미지 최대 4장, 링크 미리보기)
   - 댓글 (2단계 Nested Reply)
   - 좋아요/리액션
   - 실시간 접속 현황 (P1, 백로그)
   - DM 기능 (P2, 백로그)

3. **Celeb-map** (#9, #21)
   - 성지순례 지도 (Place/Tour)
   - Google Maps 통합
   - 장소 등록/공유

4. **유저 관리** (#10)
   - 회원가입/로그인 (이메일, Google, Apple)
   - 프로필 설정, 알림

5. **i18n** (#11, #21, #26-29)
   - 한국어/영어/일본어
   - 스레드 자동 번역 (Google Translate API)

6. **법적 안전장치** (#12, #18, #19, #20)
   - 이용약관, 개인정보처리방침, 커뮤니티 가이드라인
   - 신고 시스템, 모더레이션 도구
   - Notice & Takedown (24~72h 삭제)

## 타겟 유저 (Epic #4)

### 1순위: 글로벌 연예인 팬덤
- K-pop, 글로벌 아티스트 팬
- 페르소나: 10대 중후반~20대 초반, 멀티팬덤, 트위터 네이티브

### 2순위 (Phase 2+): 스트리머/버튜버/유튜버 팬
- 디스코드 익숙, 실시간 방송 중심 소통

### 유저 페르소나 예시
1. **성지순례 팬**: 셀럽 출신지/방문지 탐방 (지도 기능 중심)
2. **커뮤니티 활동 중심**: Threads 실시간 소통
3. **정보 수집형**: 스케줄, 뉴스, 갤러리

## Phase 2+ 확장 계획

### 셀럽 카테고리별 차별화
| 카테고리 | 추가 기능 |
|---|---|
| **연예인** | 컴백 알림, 팬사인회 정보, 굿즈 갤러리, 멤버십 연동 |
| **스트리머/버튜버** | 방송 일정, LIVE 알림, 합방 정보, 클립 갤러리 |
| **유튜버** | 업로드 알림, 조회수 트래킹, 영상 패턴 분석 |

### 공통 확장 기능
- 이벤트 캘린더 (팬미팅, 공연, 방송 통합)
- 팬 레벨 시스템 (활동량 기반 뱃지)
- DM (팬 간 1:1 메시지)

## 차별화 전략 (경쟁사 대비)

## 기술 스택
- Frontend: Next.js 16
- Backend: Supabase (Edge Functions)
- Database: Supabase (PostgreSQL)
- Storage: Supabase Storage
- Real-time: WebSocket (Supabase Realtime)
- i18n: next-i18next + Google Translate API
