## 서비스 컨셉
- **핵심**: 지도 기반 셀럽 검색 + 실시간 팬 커뮤니티
- **타겟 유저**: 연예인/유튜버/스트리머/인플루언서 팬들
- **차별화**: 크로스 팬덤 통합 + 지도 UI (기존 플랫폼 부재)

## MVP 타겟: 스트리머/버튜버 (1순위)
### 선정 이유
- 공식 플랫폼 부재 (위버스 같은 대형 서비스 없음)
- 명확한 Pain Point: 방송 일정 관리, 합방 정보 파편화
- 버컴퍼니(v-company.xyz) 같은 소규모 팬사이트만 존재

### MVP 핵심 기능 (5개)
1. 방송 일정표
2. LIVE 알림
3. 합방 표시
4. 커뮤니티 게시판
5. 팬아트 갤러리

## 글로벌 확장 전략: 실시간 번역 (2026-03-09 Roki 조사)

### 번역 기능의 비즈니스 중요성
- 전 세계 인터넷 사용자 75%가 모국어 사이트 선호
- 87%는 영어 전용 플랫폼에서 이탈
- 결론: 번역 = 글로벌 MAU 확보의 필수 조건

### 비용 분석 (기존 NMT vs LLM)
#### 기존 NMT API
| 서비스 | 100만 자당 비용 | 특징 |
|---|---|---|
| 네이버 파파고 | ₩20,000 | 한중일 강점, 무료 티어 없음 |
| 구글 번역 v2/v3 | $20.00 | 매월 50만자 무료, 광범위 언어 |
| DeepL Pro | $25.00 | 유럽권 정확도 최고 |

#### LLM 기반 번역 (2025-2026)
| 모델 | 입력 (1M 토큰) | 출력 (1M 토큰) | 특징 |
|---|---|---|---|
| **Gemini 1.5 Flash-8B** | **$0.04** | **$0.15** | 최저가, 빠른 속도 ⭐️ |
| Gemini 2.0 Flash | $0.10 | $0.40 | 고성능 멀티모달 |
| GPT-4o mini | $0.15 | $0.60 | 한국어 이해도 우수 |

**결론: LLM이 기존 NMT 대비 최대 800배 효율적**

### 한국어 토큰 세금
- 영어: 1토큰당 3~4.75자
- 한국어: 1토큰당 1.25~2.1자 (영어 대비 1.6~2.36배 비용)
- 그럼에도 LLM이 여전히 가장 경제적

### 추천 아키텍처 (3단 구성)
1. **Redis 캐싱**: 중복 번역 방지 (트위터 방식)
   - 동일 셀럽 게시물 = 수만 번 조회, 번역은 1회만
2. **온디바이스 번역**: 서버 비용 0원
   - iOS: Apple Translation Framework (iOS 17.4+)
   - Android: Google ML Kit
   - 개별 피드 탐색은 기기 내 처리
3. **LLM API**: 서버 측 공통 번역 (검색 인덱싱, 커뮤니티 흐름)
   - **1순위: Gemini 1.5 Flash-8B**

### 수익화 전략 (3단계)
#### Phase 1: 시장 침투 (런칭~6개월)
- **전략**: 모든 번역 무료 제공
- **목표**: 전 세계 팬 유입, 사용 패턴 데이터 수집
- **비용 관리**: 구글 50만자 무료 + LLM 저비용

#### Phase 2: 하이브리드 모델 (7~18개월)
- **무료 사용자**: 일일 30회 번역 무료, 초과 시 보상형 광고
- **유료 멤버십**: "스타스팟 패스" $1.99~$2.99/월
  - 무제한 번역 + 광고 제거
  - 위버스 벤치마크 ($2.50 = 심리적 저항 낮음)
- **기술 최적화**: iOS 온디바이스 우선

#### Phase 3: 슈퍼팬 멤버십 (19개월+)
- **슈퍼팬 멤버십**: $4.99/월
  - 실시간 스트리밍 음성 통번역 (STT/TTS)
  - AI 슬랭/문화 배경 해설
  - 한정판 셀럽 뱃지
- **B2B**: 소속사에 팬덤 활동 데이터 대시보드 판매
- **데이터 수익화**: 익명화 번역 데이터를 AI 학습용 코퍼스로 판매
