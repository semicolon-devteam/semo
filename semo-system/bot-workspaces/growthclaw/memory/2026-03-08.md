**출처**: Kai와 GrowthClaw의 기존 조사 (#proj-celeb-map 스레드, 2026-03-08)
**공유 경로**: SemiClaw → GrowthClaw → PlanClaw

### 1. 경쟁사 분석
- **위버스 (Weverse)**: 하이브, 4600만+ 가입자, 커뮤니티+커머스+라방 통합. 글로벌 1위지만 친밀감 약함
- **버블 (Bubble)**: 1:1 메시지 특화 (위버스 대비 친밀감 높음)
- **버컴퍼니**: 스트리머/버튜버 팬사이트 (v-company.xyz) — 방송일정, 합방 등 특화

### 2. 셀럽 카테고리별 차이점 (핵심 인사이트)
- **스트리머/버튜버**: 방송 일정, 합방 정보, LIVE 알림, 클립 갤러리 필요
- **아이돌/연예인**: 컴백, 팬사인회, 굿즈, 멤버십 중심 → 공식 플랫폼(위버스/버블) 이미  존재
- **유튜버**: 업로드 패턴, 영상 알림
- **인플루언서**: 방송 관련 기능 불필요할 수 있음

**Kai 결론**: 셀럽 유형별 기능을 다르게 제공해야 함

### 3. 1순위 타겟 추천
- **스트리머/버튜버부터 시작** — 공식 플랫폼 부재, Pain Point 명확
- Phase 1: 스트리머 3~5개 그룹
- Phase 2: 유튜버 확장
- Phase 3: 글로벌

### 4. 네이밍
- 1순위: CelebPin (SEO 경쟁 없음, 도메인 저렴)
- 2순위: StarSpot (현재 Reus가 채택)

### 5. 법적 안전장치 필수
- 이용약관에 중개자 면책 명시
- Notice & Takedown 프로세스 (24~72h 내 삭제)
- 커뮤니티 가이드라인 (초상권/저작권)
- 개인정보 처리방침 (글로벌 → GDPR/CCPA 대응)

### 6. 수익모델

- 팬 멤버십, 굿즈 수수료, 프리미엄 인사이트

### 7. 추가 조사 필요 항목

## 성지순례 카테고리 조사 (Kai 요청, 2026-03-08)

**출처**: 웹 검색 (BTS/Kpop pilgrimage 가이드, 팬 커뮤니티 사례)
**목적**: StarSpot 장소 기반 기능 카테고리 설계

### 7대 카테고리 (⚠️ 참고용 템플릿 - 셀럽 유형별 커스터마이징 필요!)

**Kai 피드백 (2026-03-08)**: 연예인과 인플루언서/버튜버는 전혀 다른 카테고리 필요. 7가지로 고정하지 말고 셀럽별 부분 적용. Phase 2 (지도 기능 개발) 때 재논의.

**연예인/아이돌 중심 카테고리 (기본 템플릿)**
1. **루츠 (Roots)**: 출생지, 학교, 연습생 숙소, 소속사
2. **먹방 (Food)**: 추천 맛집, 단골 식당, 카페, 술집
3. **촬영지 (Filming)**: MV, 드라마, 예능, 광고/화보
4. **공연/이벤트 (Events)**: 콘서트, 팬미팅, 팬사인회, 음악방송
5. **목격 장소 (Sightings)**: 공항, 거리, 헬스장 (⚠️ 사생활 경계)
6. **쇼핑/라이프스타일**: 편의점, 옷가게, 서점, 반려동물 병원
7. **팬 메이드**: 팬 카페 (예: BTS 카페 휴가), 갤러리, 응원 장소

**셀럽 유형별 차이 예시**
- 스트리머/버튜버: 방송 장소, 합방 카페, 게임 이벤트 (공연장 ❌)
- 유튜버: 브이로그 촬영지, 먹방 맛집 (팬미팅 일부만)
- 인플루언서: 패션 브랜드, 운동 장소 (공연장/방송 거의 없음)

### MVP 우선순위 (Phase 1)
1. MV/드라마 촬영지 (콘텐츠 풍부, SEO 강함)
2. 맛집/카페 (일상 접근성 높음)
3. 공연장/팬미팅 (이벤트 연계)

### 경쟁사 벤치마크
- WhatMyTrip, HallyuTrail: 촬영지 + 맛집 + 소속사 통합 가이드
- Google Maps: 팬 리뷰 ("BTS 목격") → StarSpot이 체계화 필요

### 실제 사례
- BTS 학동 숙소 → '카페 휴가' (전 세계 ARMY 성지)
- Stray Kids JYP 건물, 연습생 시절 식당
- IU Celebrity MV 촬영지: 을왕리 해수욕장
