### Fix Implementation (16:23-16:30)

#### 1. PixiJS Memory Leak Fix
**Issue**: agents 변경마다 PixiJS app 재생성 → 메모리 누수

**Solution**:
- useEffect 분리:
  - First useEffect: PixiJS app 초기화 (한 번만)
  - Second useEffect: agents 변경 시 agentContainer만 업데이트
- `agentContainerRef` 추가
- Grid는 한 번만 생성, agents sprites만 동적 업데이트

**Files**: `OfficeView.tsx`

#### 2. XSS Vulnerability Fix
**Issue**: 사용자 입력/메시지 sanitization 없음

**Solution**:
- Install: `isomorphic-dompurify`
- Sanitize command input before API submission (OrderZone)
- Sanitize last_message before rendering speech bubble (OfficeView)
- Use `{ ALLOWED_TAGS: [] }` to strip all HTML tags

**Files**: `OrderZone.tsx`, `OfficeView.tsx`

### Lessons Learned
- PixiJS app initialization should be separated from data rendering
- Always sanitize user input and untrusted data (agent messages from DB)
- Memory leak prevention requires careful useEffect dependency management
- DOMPurify with `ALLOWED_TAGS: []` ensures plain text only
