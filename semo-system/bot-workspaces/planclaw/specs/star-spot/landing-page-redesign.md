# Star Spot 랜딩 페이지 재설계 - 셀럽 리스트형

## 📋 요약
기존 지도 기반 랜딩에서 **셀럽 리스트 기반 랜딩**으로 변경. 사용자가 셀럽을 먼저 탐색하고, 관심 있는 셀럽의 맛집을 확인하는 플로우로 전환.

---

## 🎯 목표
- 셀럽 중심 탐색 경험 제공
- 타입별 카테고리로 명확한 구분
- 직관적인 필터 UX
- 전체 지도 뷰는 별도 탭으로 분리

---

## 📱 UI 구조

### 1. 상단 영역
```
┌─────────────────────────┐
│    [Search Bar]         │  ← 셀럽 이름 검색
├─────────────────────────┤
│  [Filter Container]     │  ← 필터 아이콘 + 현재 필터 상태 표시
└─────────────────────────┘
```

#### Search Bar
- 플레이스홀더: "셀럽 이름으로 검색"
- 실시간 검색 (입력 시 즉시 필터링)
- 검색 결과 0건 시: "'{검색어}'에 해당하는 셀럽이 없습니다" 안내

#### Filter Container
- **좌측**: 필터 아이콘 (🔽 형태)
- **우측**: 현재 적용된 필터 상태 요약 표시
  - 예: "배우 · 인기순" / "전체 · 최신순"
- 터치 시 → 필터 팝업 오픈

---

### 2. 셀럽 리스트 (3열 그리드)
```
○ ○ ○
○ ○ ○
○ ○ ○
```

#### 셀럽 아이템 구성
- **원형 프로필 이미지** (3:3 비율)
- **이름** (이미지 하단 중앙 정렬)
- **방문 맛집 수** (작은 텍스트, 예: "12곳")
- 터치 시 → 셀럽 상세 페이지로 이동

#### 무한 스크롤
- 스크롤 시 추가 셀럽 로드 (페이지네이션)
- 로딩 인디케이터 표시

---

### 3. 필터 팝업

#### 팝업 UI
- 바텀 시트 형태 (하단에서 슬라이드 업)
- 배경 딤드 처리 (터치 시 팝업 닫기)
- 상단: "필터" 타이틀 + [초기화] 버튼 + [닫기] 버튼

#### 필터 항목

**1) 셀럽 타입 (단일 선택)**
- [ ] 전체
- [ ] 배우
- [ ] 아이돌
- [ ] 스트리머
- [ ] 인플루언서

**2) 정렬 방식 (단일 선택)**
- [ ] 인기순 (방문 맛집 수 기준, 내림차순)
- [ ] 가나다순
- [ ] 최신 등록순 (DB 등록 시간 기준, 내림차순)

**3) 특성 필터 (다중 선택, 추후 확장 가능)**
- [ ] 방문 맛집 10곳 이상
- [ ] 서울 지역 집중
- [ ] 최근 1개월 활동
- _(향후 추가 가능: 음식 카테고리, 지역 등)_

#### 적용 플로우
1. 사용자가 필터 선택
2. [적용] 버튼 터치 → 팝업 닫기 + 리스트 갱신
3. Filter Container에 현재 필터 상태 반영
4. 셀럽 리스트 API 재호출 (필터 파라미터 포함)

#### 초기화 동작
- [초기화] 버튼: 모든 필터를 기본값으로 되돌림
  - 타입: 전체
  - 정렬: 인기순
  - 특성: 선택 해제

## 🗺️ 전체 지도 뷰 처리

### 기존 vs 변경
| | 기존 | 변경 후 |
|---|---|---|
| **랜딩** | 전체 지도 뷰 | 셀럽 리스트 |
| **지도 접근** | 랜딩 = 지도 | 바텀 네비 "지도" 탭 |

### 지도 탭 기능
- **전체 맛집 핀 표시** (모든 셀럽의 방문 맛집)
- 핀 터치 시 → 맛집 상세 페이지
- 셀럽별 필터 적용 가능 (예: "이효리가 방문한 맛집만 보기")
- 현재 위치 기반 탐색 지원

## 🧭 바텀 네비게이션 구성

```
┌────────┬────────┬────────┬────────┐
│  홈    │  지도   │  검색   │  MY   │
│  🏠    │  🗺️    │  🔍    │  👤   │
└────────┴────────┴────────┴────────┘
```

### 탭별 기능

#### 1) 홈 (기본 랜딩)
- 셀럽 리스트 페이지 (본 기획서의 메인)
- Search Bar + Filter + 3열 그리드

#### 2) 지도
- 전체 맛집 지도 뷰
- 핀 클러스터링 (줌 아웃 시 그룹화)
- 필터: 셀럽별, 지역별, 음식 카테고리별

#### 3) 검색
- 통합 검색 페이지
  - 셀럽 검색
  - 맛집 검색
  - 지역 검색
- 최근 검색어 / 인기 검색어 표시

#### 4) MY (마이페이지)
- 좋아하는 셀럽
- 북마크한 맛집
- 내가 방문한 곳
- 설정

## 🔄 사용자 플로우

### 메인 플로우
```
앱 실행
  ↓
홈(셀럽 리스트) 랜딩
  ↓
[옵션 1] 검색 → 셀럽 검색 → 셀럽 선택 → 셀럽 상세
  ↓
[옵션 2] 필터 → 타입/정렬/특성 선택 → 적용 → 필터링된 리스트
  ↓
[옵션 3] 스크롤 → 셀럽 발견 → 셀럽 선택 → 셀럽 상세
  ↓
셀럽 상세 페이지
  ├─ 프로필 정보
  ├─ 방문 맛집 리스트
  └─ 작은 지도 뷰 (해당 셀럽의 맛집 핀만 표시)
```

### 지도 탭 플로우
```
바텀 네비 "지도" 탭
  ↓
전체 맛집 지도 뷰
  ↓
핀 터치 → 맛집 상세 페이지
  ↓
맛집 방문한 셀럽 목록 표시
```

## 🛠️ 구현 요구사항

### API 엔드포인트

#### 1) 셀럽 리스트 조회
```
GET /api/celebrities

Query Params:
- type: string (all | actor | idol | streamer | influencer)
- sort: string (popularity | name | latest)
- minRestaurants: number (optional, 예: 10)
- page: number
- limit: number (기본 18개, 3열 × 6행)

Response:
{
  "celebrities": [
    {
      "id": "uuid",
      "name": "이효리",
      "profileImage": "https://...",
      "type": "actor",
      "restaurantCount": 12,
      "createdAt": "2025-01-15T..."
    }
  ],
  "total": 120,
  "page": 1,
  "hasNext": true
}
```

#### 2) 셀럽 검색
```
GET /api/celebrities/search

Query Params:
- q: string (검색어)
- page: number
- limit: number

Response: (위와 동일 구조)
```

### 프론트엔드 컴포넌트

#### 필수 컴포넌트
- `CelebListPage` (메인 컨테이너)
- `SearchBar` (검색 입력)
- `FilterContainer` (필터 상태 표시)
- `FilterPopup` (바텀 시트 필터)
- `CelebGrid` (3열 그리드)
- `CelebCard` (셀럽 아이템)
- `BottomNavigation` (바텀 네비)

#### 상태 관리
```typescript
interface FilterState {
  type: 'all' | 'actor' | 'idol' | 'streamer' | 'influencer';
  sort: 'popularity' | 'name' | 'latest';
  minRestaurants?: number;
  seoulFocus?: boolean;
  recentActivity?: boolean;
}

interface CelebListState {
  celebrities: Celebrity[];
  filter: FilterState;
  searchQuery: string;
  page: number;
  hasNext: boolean;
  loading: boolean;
}
```
