## 📊 GrowthClaw 번역 기능 시장조사 (2026-03-09, Roki 전달)

### 핵심 결론
- **LLM 기반 번역**이 기존 NMT(파파고, 구글, DeepL) 대비 **최대 800배** 경제적
- **Gemini 1.5 Flash-8B**: $0.04/1M input, $0.15/1M output (최저가)
- **GPT-4o mini**: $0.15/1M input, $0.60/1M output (한국어 강점)
- 한국어 토큰 세금: 영어 대비 1.6~2.36배 토큰 소요 (그래도 저렴)

### 비용 시뮬레이션 (MAU 50만 기준)
- 월간 총 번역 토큰: 75억 토큰 (사용자당 일 10회, 50토큰/회)
- **API 비용**: 약 $750/월 (Gemini 1.5 Flash 기준)
- **광고 수익**: 약 $5,000/월 (보상형 광고)
- **멤버십**: MAU 2% 전환 시 $25,000/월 ($2.50 구독료)
→ 번역 비용은 매출 대비 **5% 미만** 관리 가능

### 기술 스택 권장
1. **LLM**: Gemini 1.5 Flash-8B (초저가) 또는 GPT-4o mini (한국어)
2. **캐싱**: Redis (중복 번역 방지, Cache-aside 패턴)
3. **온디바이스**: iOS Translation Framework (iOS 17.4+), Google ML Kit (Android)
4. **하이브리드**: 서버(커뮤니티 전체) + 온디바이스(개인 피드)

### 경쟁사 벤치마크
- **위버스**: 디지털 멤버십 $2.50~$2.99 (실시간 라이브 번역 유료)
- **디어유 버블**: 구독료에 번역 포함 ($3.99/아티스트)
- **디스코드 봇**: 무료(1만자 제한) → 프리미엄 €9.99/월 (무제한)

### 단계별 수익화 전략
1. **1단계 (0~6개월)**: 전면 무료 (시장 침투, 데이터 수집)
2. **2단계 (7~18개월)**: 정량제 + 광고 (일 30회 제한, 초과 시 광고)
3. **3단계 (19개월+)**: 슈퍼팬 멤버십 $4.99 (실시간 STT/TTS, 슬랭 해설)

### 리스크
- 신조어/슬랭 처리 → 글로사리 API 연동
- 환각(Hallucination) → MTPE(기계번역+인간검수) 하이브리드
