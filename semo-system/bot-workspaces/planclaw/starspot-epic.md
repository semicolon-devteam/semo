# StarSpot Epic — 글로벌 팬 커뮤니티 플랫폼

## 📋 프로젝트 개요

**프로젝트명**: StarSpot  
**컨셉**: 연예인/유명인 팬들을 위한 종합 커뮤니티 플랫폼  
**목표**: 팬들이 셀럽 관련 모든 것(소통, 정보 확인, 니즈 충족)을 할 수 있는 글로벌 서비스  
**레포**: `semicolon-devteam/proj-celeb-map`  
**Owner**: Kai (견습 엔지니어)  
**PM**: PlanClaw  

## 🎯 프로젝트 목표

### 문제 정의
- **기존 팬 플랫폼의 한계**:
  - 위버스/버블: 특정 엔터사 전용 (하이브, SM 등), 글로벌 팬덤 분산
  - 버컴퍼니: 스트리머/버튜버 특화, 연예인 팬 커버 부족
  - 친밀감 vs 기능성 트레이드오프 (버블=친밀, 위버스=기능)

- **팬들의 Pain Points**:
  - 셀럽별로 다른 플랫폼 사용 (정보 분산)
  - 실시간 소통 공간 부족
  - 셀럽 유형별 맞춤 기능 부재 (스트리머 vs 아이돌 vs 유튜버 니즈 다름)

### 솔루션
- **범용 팬 플랫폼**: 엔터사/셀럽 유형 제한 없는 글로벌 서비스
- **코어 기능 (스레드)**: 모든 셀럽에게 공통 적용되는 실시간 대화 공간
- **차별화 전략**: 셀럽 카테고리별 맞춤 기능 추가 (Phase 2+)

## 👥 타겟 유저

### 1순위 타겟
- **글로벌 연예인 팬덤**
  - 팬덤 규모가 큰 연예인 우선 (K-pop, 글로벌 아티스트)
  - 국적 제한 없음 (다국어 지원 고려)

### 유저 페르소나 (예시)
1. **성지순례 팬**  
   - 좋아하는 셀럽의 출신지/방문지 탐방
   - 지도 기능, 장소 정보 중요
   
2. **커뮤니티 활동 중심 팬**  
   - 다른 팬들과 실시간 소통
   - 스레드 기능, 실시간 채팅 중요
   
3. **정보 수집형 팬**  
   - 셀럽 스케줄, 뉴스, 사진/영상
   - 일정 알림, 갤러리 기능 중요

### 2순위 타겟 (Phase 2 중반 이후)
- **스트리머/버튜버 팬** (데이터 기반 우선순위 조정)
- **유튜버 팬**
- **인플루언서 팔로워**

**우선순위 결정 방식** (Kai 지시, 2026-03-15):
- MVP 런칭 후 카테고리별 팔로우 수, 스레드 활동량 측정
- 데이터 기반으로 스트리머/유튜버 차별화 순서 결정

## 💰 비즈니스 모델

### MVP 단계
1. **광고**: 배너/네이티브 광고 (초기 수익)
2. **엔터사 협업**: 공식 프로필 제공, 굿즈/티켓 판매 제휴

### 확장 단계 (Phase 2+)
3. **팬 멤버십**: 프리미엄 기능 (뱃지, 우선 댓글 등)
4. **굿즈 수수료**: 커뮤니티 내 굿즈 거래 중개
5. **프리미엄 인사이트**: 팬덤 분석 데이터 판매 (엔터사 대상)

## 🚀 MVP 스코프 (Phase 1) — 3월 런칭 목표

### 핵심 기능: 스레드 (실시간 대화 공간)

#### 1. 셀럽 선택
- **검색**: 셀럽 이름 검색
- **필터**: 
  - 카테고리 (연예인, 스트리머, 유튜버 등)
  - 국적
  - 인기순 정렬
- **셀럽 프로필 카드**:
  - 프로필 이미지
  - 이름 (본명 + 예명)
  - 카테고리 태그
  - 팔로워 수 (플랫폼 내)

#### 2. 스레드 기능
- **스레드 타임라인**:
  - 최신순 정렬 (실시간 업데이트)
  - 글 작성 (텍스트, 이미지, 링크)
  - 댓글 (Nested reply 지원)
  - 좋아요/리액션
  
- **실시간 대화**:
  - WebSocket 기반 실시간 동기화
  - 타이핑 인디케이터
  - 읽음 표시 (선택적)

- **모더레이션**:
  - 신고 기능 (스팸, 욕설, 저작권 침해 등)
  - Notice & Takedown (24~72h 내 삭제)

#### 3. 유저 관리
- **회원가입/로그인**:
  - 이메일/소셜 로그인 (Google, Apple)
  - 프로필 설정 (닉네임, 아바타)
  
- **내 활동**:
  - 팔로우한 셀럽 목록
  - 내 작성 글/댓글
  - 알림 (댓글, 좋아요, 팔로우 셀럽 새 글)

#### 4. 법적 안전장치

**초상권/저작권 전략** (위버스 벤치마크):
- **공식 콘텐츠 업로드 금지**:
  - 소속사/엔터사가 소유한 공식 사진/영상은 업로드 불가
  - 저작권 침해 리스크 회피
  
- **팬 생성 콘텐츠만 허용**:
  - 팬이 직접 촬영한 공연 사진, 성지순례 사진
  - 팬아트, 2차 창작물 (단, 상업적 이용 금지)
  - ❌ 금지: TV 캡처, 뮤직비디오 스크린샷, 공식 화보 등
  
- **이용약관**:
  - 중개자 면책 명시: "회원이 작성한 콘텐츠로 인한 손해는 회사가 책임지지 않음"
  - 침해 콘텐츠 발생 시 법적 책임은 게시자가 부담
  
- **커뮤니티 가이드라인**:
  - 초상권/저작권 존중
  - 금지 행위: 타인 명예훼손, 욕설/음란, 저작권/초상권 침해
  
- **신고/삭제 프로세스 (Notice & Takedown)**:
  - 신고 일정 횟수 이상 → 자동 임시삭제
  - 소속사/권리자 요청 시 24~72h 내 수동 삭제
  - 반복 위반 → 게시 제한/계정 정지
  
- **개인정보 처리방침**: GDPR/CCPA 대응 (글로벌)

### 기술 스택 (가정 — Kai 확인 필요)
- **Frontend**: React / Next.js
- **Backend**: Node.js / Kotlin Spring Boot
- **Database**: PostgreSQL / Supabase
- **Real-time**: WebSocket (Socket.io / Supabase Realtime)
- **Storage**: S3 / Cloudflare R2 (이미지/미디어)
- **Auth**: Supabase Auth / Firebase Auth

### 배포 환경
- **MVP**: Vercel (Frontend) + Supabase (Backend/DB)
- **CDN**: Cloudflare
- **Monitoring**: Sentry

## 🔮 Phase 2+ — 셀럽 카테고리별 차별화

**우선순위 전략** (Kai 확정, 2026-03-15):
1. **연예인 특화 기능 먼저** (Phase 2 초반)
2. **MVP 데이터 분석** → 카테고리별 활동량 측정
3. **스트리머/유튜버 특화** (Phase 2 중반 이후, 데이터 기반 결정)

### Phase 2 초반: 연예인 특화 기능 (우선순위 1)
- **컴백 알림**: 신곡/앨범 발매일 자동 알림
- **팬사인회 정보**: 일정, 신청 링크
- **굿즈 갤러리**: 공식/비공식 굿즈 공유
- **멤버십 연동**: 팬클럽 멤버 뱃지

**타겟**: K-pop 팬덤 (글로벌 8억 명, 코어팬 350만)  
**이유**: 팬덤 규모 크고, 시장 검증 빠름

### Phase 2 중반: 스트리머/버튜버 특화 기능 (데이터 기반)
- **방송 일정**: 스트리밍 스케줄 캘린더
- **LIVE 알림**: 방송 시작 푸시 알림
- **합방 정보**: 콜라보 스트림 일정
- **클립 갤러리**: 명장면 공유

**조건**: MVP 런칭 후 스트리머 카테고리 활동량이 높을 경우 우선순위 상향

### Phase 2 후반: 유튜버 특화 기능
- **업로드 알림**: 신규 영상 자동 알림
- **영상 패턴 분석**: 업로드 주기 예측
- **조회수/좋아요 트래킹**: 인기 영상 순위

### 공통 확장 기능 (Phase 2 전반)
- **지도 (Map)**: 셀럽 출신지/방문지 마킹 (원래 컨셉 복원)
- **이벤트 캘린더**: 팬미팅, 공연, 방송 일정 통합
- **팬 레벨 시스템**: 활동량 기반 레벨업, 뱃지
- **DM**: 팬끼리 1:1 메시지 (선택적)
