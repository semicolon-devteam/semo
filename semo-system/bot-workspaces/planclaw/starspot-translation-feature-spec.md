# 스타스팟(StarSpot) 번역 기능 기획서

**작성자**: PlanClaw  
**작성일**: 2026-03-09  
**버전**: 1.0 (MVP)  
**프로젝트**: StarSpot / CelebPin (스트리머/버튜버 팬 커뮤니티)

---

## 📋 문서 개요

### 배경
글로벌 팬덤 경제의 성장과 함께, 스트리머/버튜버 팬들은 **국경을 초월한 실시간 소통**을 갈구한다. 특히 한국 스트리머를 좋아하는 해외 팬, 일본 버튜버를 좋아하는 한국 팬 등 **언어 장벽**이 팬 활동의 가장 큰 Pain Point다.

스타스팟은 **지도 기반 셀럽 검색 + 실시간 팬 커뮤니티**를 제공하므로, 커뮤니티 게시물, 댓글, 팬아트 설명 등 **대량의 UGC(사용자 생성 콘텐츠)**가 발생한다. 이를 실시간으로 번역하여 글로벌 팬들이 소외감 없이 참여할 수 있도록 하는 것이 본 기능의 핵심 목표다.

### 목표
1. **팬덤 글로벌화**: 언어 장벽 제거 → MAU 증가
2. **저비용 운영**: LLM + 캐싱으로 번역 비용을 매출 대비 5% 미만으로 관리
3. **수익화 기반 마련**: 무료 → 정량제 → 멤버십 단계적 전환

## 🎯 핵심 기능 스펙 (MVP)

### 1. 번역 대상 콘텐츠
- ✅ **커뮤니티 게시물** (텍스트, 제목)
- ✅ **댓글/답글**
- ✅ **팬아트 설명**
- ✅ **방송 일정표** (스트리머 공지사항)
- ❌ **실시간 채팅** (Phase 2 — 비용/기술 복잡도 높음)
- ❌ **LIVE 스트림 자막** (Phase 3 — STT/TTS 필요)

### 2. 지원 언어 (1단계)
- **한국어 ↔ 영어** (최우선)
- **한국어 ↔ 일본어** (버튜버 팬덤)
- **한국어 ↔ 중국어 간체** (아시아 시장)

**확장 계획 (2단계):**
- 스페인어, 포르투갈어, 태국어, 베트남어 (K-콘텐츠 강세 지역)

### 3. 번역 트리거 방식
**A. 수동 번역 (MVP 채택)**
- 트위터 스타일 **"번역보기"** 버튼
- 사용자가 명시적으로 클릭 → API 호출
- 캐싱 활용 (동일 게시물 재번역 방지)

**B. 자동 번역 (Phase 2)**
- 사용자 언어 설정에 따라 자동으로 번역된 텍스트 표시
- 토글 버튼으로 원문 ↔ 번역본 전환

### 4. UI/UX 스펙

#### 게시물/댓글 번역 UI
```
┌─────────────────────────────────────┐
│ @streamer_fan_kr                    │
│ 오늘 방송 진짜 레전드였어 ㅋㅋㅋ       │
│ 합방 케미 미쳤다                      │
│                                     │
│ [번역보기 ▼]                        │  ← 버튼 (클릭 전)
└─────────────────────────────────────┘

↓ 클릭 후

┌─────────────────────────────────────┐
│ @streamer_fan_kr                    │
│ 오늘 방송 진짜 레전드였어 ㅋㅋㅋ       │
│ 합방 케미 미쳤다                      │
│                                     │
│ ┌─────────────────────────────────┐ │
│ │ 🌐 영어로 번역됨                 │ │
│ │ Today's stream was legendary lol │ │
│ │ The collab chemistry was insane  │ │
│ │ [원문 보기]                      │ │  ← 토글
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

#### 버튼 위치 및 디자인
- **위치**: 게시물/댓글 하단 (좋아요, 댓글 버튼과 동일 라인)
- **아이콘**: 🌐 (지구본) 또는 언어 코드 표시 (KR → EN)
- **색상**: 그레이 (비활성화) → 블루 (활성화)
- **애니메이션**: 번역 중 스피너 표시 (로딩 0.5~1초)

#### 언어 선택 (설정 페이지)
- **기본값**: 브라우저/앱 언어 자동 감지
- **수동 설정**: 프로필 > 언어 설정 > "번역 대상 언어" 드롭다운
- **저장**: 로컬 스토리지 + 서버 동기화 (로그인 시)

## 🛠️ 기술 스택 권장안

### A. 번역 엔진 선택
**MVP 추천: Gemini 1.5 Flash-8B**
- **이유**: 최저 비용 ($0.04/1M input, $0.15/1M output)
- **성능**: 일반 SNS 게시물 번역에 충분
- **속도**: 지연시간 1초 내외

**대안 1: GPT-4o mini**
- **비용**: $0.15/1M input, $0.60/1M output (Gemini 대비 3.75배)
- **장점**: 한국어 신조어/슬랭 처리 우수
- **추천 시나리오**: 유료 멤버십 고품질 번역

**대안 2: 네이버 파파고**
- **비용**: 20,000 KRW/1M자 (약 $15)
- **장점**: 한일중 번역 품질, GDPR 안전
- **단점**: LLM 대비 75배 비쌈
- **추천 시나리오**: 공식 공지사항, 법적 문서

### B. 캐싱 아키텍처 (필수)
**Redis Cache-aside 패턴**

```
사용자 "번역보기" 클릭
     ↓
앱 → Redis 캐시 조회 (key: post_id + target_lang)
     ↓
 있음? → 즉시 반환 (비용 0, 지연 <50ms)
     ↓
 없음? → LLM API 호출 → 결과를 Redis에 저장 (TTL 7일)
           ↓
         사용자에게 반환
```

**기대 효과:**
- 동일 게시물 재번역 요청 시 비용 0원
- 인기 게시물(조회수 10,000+)의 경우 99.9% 캐시 히트
- 월 번역 비용 **80~90% 절감** (시뮬레이션 기준)

**Redis 설정:**
- **TTL**: 7일 (게시물 신선도 유지)
- **메모리**: 초기 2GB (MAU 50만 기준)
- **클러스터**: AWS ElastiCache 또는 Upstash (서버리스)

### C. 온디바이스 번역 (비용 최적화)
**iOS: Translation Framework (iOS 17.4+)**
- 사용자 기기에서 번역 수행 → **서버 비용 0원**
- 언어팩 다운로드 (1회) → 오프라인 번역 가능
- **제한**: 59개 언어만 지원, 문맥 이해 낮음

**Android: Google ML Kit**
- 유사한 기능, 온디바이스 처리
- **활용 시나리오**: 개인 피드 탐색, 댓글 미리보기

**하이브리드 전략 (권장):**
- **개인 피드**: 온디바이스 우선 → 실패 시 서버
- **커뮤니티 전체**: 서버 번역 + Redis 캐싱
- **공식 공지**: 서버 + MTPE(인간 검수)

### D. 신조어/슬랭 처리
**글로사리(Glossary) API 연동**
- 스트리머별 고유 용어 사전 구축
  - 예: "알잘딱깔센" → "You know what I mean" (맥락)
  - 예: "ㅋㅋㅋ" → "lol" (이모티콘)
- **구축 방법**: 팬 크라우드소싱 + AI 자동 추출

**MTPE (Machine Translation Post-Editing) — Phase 2**
- 공식 공지사항: AI 번역 → 숙련 팬/전문가 검수
- 비용 절감: 순수 인간 번역 대비 40~60% 저렴
- 정확도: 97% 이상

- ✅ 모든 게시물/댓글 번역 무료 무제한
- ✅ 3개 언어 쌍 (한↔영, 한↔일, 한↔중)
- ✅ "번역보기" 버튼 (수동 트리거)

**기술:**
- LLM: Gemini 1.5 Flash-8B
- 캐싱: Redis (히트율 70% 목표)
- 온디바이스: iOS/Android 보조 활용

**비용 예측 (MAU 50만):**
- 월 API 비용: $750
- 광고 없음 (사용자 경험 우선)
- **손실 감수**: 초기 사용자 확보가 최우선

**측정 지표:**
- 번역 버튼 클릭률 (CTR)
- 번역 후 체류 시간 증가율
- 해외 사용자 비율 (목표: 30% 이상)

### Phase 2: 정량제 + 광고 (7~18개월)
**목표**: 수익 전환 + 헤비 유저 식별

- 🆓 **무료 사용자**: 일 30회 번역 제공

**기술 업그레이드:**
- 무료: Gemini 1.5 Flash-8B
- 유료: GPT-4o mini (고품질)
- 자동 번역 모드: 피드 로딩 시 백그라운드 번역

**비용 예측:**

**측정 지표:**
- 무료→유료 전환율 (목표: 10%)
- 광고 시청률 (목표: 60%)
- 유료 사용자 이탈률 (목표: <5%)

### Phase 3: 슈퍼팬 멤버십 (19개월 이후)
**목표**: 충성 고객 수익화 + B2B 확장

**슈퍼팬 멤버십 ($4.99/월):**
- ✅ 모든 Phase 2 혜택
- ✅ **실시간 스트림 자막** (STT → 번역 → TTS)
- ✅ **AI 슬랭 해설**: 현지 문화/맥락 설명
  - 예: "개추" → "I agree (Korean slang, literal: dog recommendation)"
- ✅ **셀럽 지도 한정판 뱃지** (번역왕 배지)
- ✅ **오프라인 번역** (언어팩 다운로드)

**B2B 라이선싱:**
- 스트리머/소속사 대상 **팬덤 데이터 대시보드** 판매
  - 어떤 지역에서 어떤 언어로 우리 스트리머 정보가 공유되는지
  - 해외 팬 비율, 번역 요청 빈도
  - → 월드 투어, 광고 타겟팅 전략 수립에 활용

**데이터 수익화 (선택적):**

- **주의**: GDPR/CCPA 준수, 사용자 동의 필수

## ⚠️ 리스크 관리

### 1. 번역 품질 저하
**리스크**: 신조어/은어 오역 → 팬들의 불만 → 이탈

**대응책:**
- **글로사리 API** 연동 (스트리머별 용어 사전)
- **사용자 피드백 루프**: "번역 신고하기" 버튼
  - 오역 신고 → 인간 검수 → 글로사리 업데이트
- **MTPE**: 공식 공지는 AI + 인간 검수 병행

### 2. 비용 폭발 (Runaway Cost)
**리스크**: 봇 공격, 악의적 사용자의 무한 번역 요청

**대응책:**
- **Rate Limiting**: IP당 분당 10회, 사용자당 일 300회
- **CAPTCHA**: 의심 행동 감지 시 자동 발동
- **캐싱 강화**: 동일 요청 재사용률 90% 목표

### 3. GDPR/CCPA 위반
**리스크**: 번역 API에 사용자 개인정보 전송 → 법적 제재

**대응책:**
- **마스킹(Masking)**: 번역 요청 시 사용자 ID, 위치 정보 제외
  - 전송 데이터: 텍스트 원문만
- **DPA(Data Processing Agreement)**: 구글, OpenAI와 계약 체결
- **약관 명시**: "번역 기능 사용 시 텍스트가 제3자 AI 서비스로 전송됨" 고지

### 4. 서비스 의존성 (Vendor Lock-in)
**리스크**: Gemini API 장애 → 번역 기능 전면 중단

**대응책:**
- **멀티 프로바이더 아키텍처**: Gemini 실패 시 GPT-4o mini로 폴백
- **우선순위 큐**: 유료 사용자 요청 우선 처리
- **온디바이스 폴백**: API 다운 시 로컬 번역 제공 (품질 낮지만 가용성 유지)
