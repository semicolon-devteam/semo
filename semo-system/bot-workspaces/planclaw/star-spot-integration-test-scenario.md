# StarSpot MVP 통합테스트 시나리오

## 테스트 목적
StarSpot MVP (Phase 1) 핵심 기능 통합 검증
- 완료된 Feature: #7~#12, #16, #20, #21
- 대기 중: #19 (신고 시스템)

---

## E2E 시나리오

### 시나리오 1: 신규 유저 온보딩 → 셀럽 팔로우 → Threads 참여

**목적:** 기본 유저 플로우 검증

**Steps:**
1. **회원가입/로그인** (#10 유저 관리)
   - [ ] 신규 유저 등록 (OAuth/이메일)
   - [ ] 프로필 설정 (닉네임, 언어 선택)
   - [ ] i18n 언어 전환 (한/영/일) (#11)

2. **셀럽 탐색 및 팔로우** (#7 셀럽 선택)
   - [ ] 카테고리별 셀럽 탐색 (연예인/스트리머/유튜버/인플루언서)
   - [ ] 검색 기능 (셀럽 이름, 태그)
   - [ ] 셀럽 팔로우/언팔로우
   - [ ] 필터링 (카테고리, 인기도)

3. **Threads 참여** (#8 실시간 대화)
   - [ ] 타임라인 조회 (최신순, 인기순)
   - [ ] 스레드 작성 (텍스트, 이미지)
   - [ ] 댓글 작성/좋아요
   - [ ] WebSocket 실시간 업데이트 확인
   - [ ] 자동 번역 동작 확인 (#11 i18n)

**예상 결과:**
- 모든 UI 요소가 선택한 언어로 표시됨
- 실시간 데이터 동기화 정상 작동
- 번역된 콘텐츠 표시 (다른 언어 게시물)

---

### 시나리오 2: 성지순례 지도 탐색 → 장소 등록 → 투어 생성

**목적:** Celeb-map 핵심 기능 검증

**Steps:**
1. **Place 탐색** (#9 Celeb-map)
   - [ ] Google Maps 통합 확인
   - [ ] 셀럽별 Place 필터링
   - [ ] 지도 마커 클릭 → 상세 정보 표시
   - [ ] Place 검색 (주소, 장소명)

2. **Place 등록** (#9)
   - [ ] 신규 Place 등록 (위치, 사진, 설명)
   - [ ] 셀럽 태그 연결
   - [ ] i18n 필드 입력 (다국어 설명) (#21)

3. **Tour 생성** (#9)
   - [ ] Place 여러 개 선택
   - [ ] Tour 루트 설정
   - [ ] Tour 공유/저장

**예상 결과:**
- Google Maps API 정상 연동
- Place/Tour 데이터 정확히 저장/조회
- 다국어 필드 번역 적용 (#21 보완 완료)

---

### 시나리오 3: 모더레이션 → 신고 처리 → 법적 안전장치

**목적:** 안전 시스템 검증

**Steps:**
1. **콘텐츠 신고** (#19 신고 시스템 - 대기 중)
   - [ ] 부적절한 게시물 신고
   - [ ] 신고 사유 선택 (스팸/욕설/초상권 침해/저작권)
   - [ ] 신고 접수 확인

2. **관리자 모더레이션** (#20 모더레이션 도구)
   - [ ] 관리자 페이지 접근 (권한 체크)
   - [ ] 신고 대시보드 조회
   - [ ] 신고 처리 (승인/기각)
   - [ ] 유저 제재 (경고/정지/영구 차단)
   - [ ] 콘텐츠 삭제

3. **법적 안전장치** (#12)
   - [ ] Notice & Takedown 프로세스 확인
   - [ ] 초상권/저작권 침해 신고 플로우
   - [ ] 법적 고지 표시 (이용약관, 개인정보처리방침)

**예상 결과:**
- 신고 → 처리 → 제재 파이프라인 정상 작동
- 권한 없는 유저는 관리자 페이지 접근 차단
- 법적 고지 UI 정확히 표시

---

### 시나리오 4: 인프라 헬스체크

**목적:** 배포 준비 상태 확인

**Steps:**
1. **Health Endpoint** (#16)
   - [ ] `/api/health` 응답 확인 (200 OK)
   - [ ] K8S liveness/readiness probe 동작

2. **GA4 데이터 수집** (Epic #4 요구사항)
   - [ ] 페이지뷰 트래킹
   - [ ] 이벤트 트래킹 (회원가입, 셀럽 팔로우, 게시물 작성)
   - [ ] GA4 대시보드 데이터 확인

**예상 결과:**
- Health endpoint 정상 응답
- GA4 이벤트 실시간 수집 확인

## Cross-Cutting 검증 항목

### i18n (다국어) (#11, #21)
- [ ] 한/영/일 언어 전환 시 모든 UI 정상 표시
- [ ] 누락된 번역 키 없음 (#21 보완 완료)
- [ ] 환경변수 상수화 확인 (#21)
- [ ] 자동 번역 API 동작 (게시물, 댓글)

### 성능
- [ ] 페이지 로드 시간 < 3초
- [ ] WebSocket 지연 < 500ms
- [ ] Google Maps 렌더링 정상

### 보안
- [ ] 권한 체크 (관리자/일반 유저)
- [ ] SQL Injection/XSS 방어
- [ ] Rate limiting (API 호출 제한)

### UX
- [ ] 모바일 반응형 디자인
- [ ] 에러 메시지 명확성
- [ ] 로딩 인디케이터 표시
